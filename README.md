DROPZONE — демонстрационный сайт CS2 Case Simulator

Запуск:
1. Распакуйте архив.
2. Откройте index.html в современном браузере (Chrome, Edge, Firefox).
3. Интернет и сервер не требуются.

Возможности:
- 30 кейсов от 25 до 50 000 ₽;
- SVG-иллюстрации кейсов и предметов (не эмодзи, встроены в HTML);
- демо-пополнение;
- открытие кейсов с анимацией;
- проценты выпадения по каждому предмету;
- апгрейд x0.1–x10;
- контракты на 3–10 предметов;
- инвентарь, правила и политика конфиденциальности.

Важно:
Все предметы, цены, вероятности, баланс и операции являются условной демонстрацией.
Сайт не подключён к Steam/Valve, не принимает платежи и не выдаёт игровые предметы.
Для коммерческого запуска потребуется backend, серверная генерация случайных результатов,
проверяемая система вероятностей, юридическая проверка и реальные политики под юрисдикцию.
